# Game Space Design Lab

This is a static webpage. It does not require a build step, database, or server-side code.

## Add it to an existing GitHub Pages site

1. Create a folder in the repository, such as `game-space-design-lab`.
2. Upload `index.html`, `styles.css`, and `app.js` into that same folder.
3. Commit the files.
4. Open the folder URL on the GitHub Pages site, for example: `https://YOUR-SITE/game-space-design-lab/`.

The webpage uses relative links (`./styles.css` and `./app.js`), so its styling and interactions will work whether the files are placed at the site root or together in a subfolder.

Student notes are saved in that browser on that device using local storage. They are not sent to GitHub.
